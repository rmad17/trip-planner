  1. Database Schema (migrations/20251231000000_create_travel_documents.sql)

  - PostgreSQL table with pgvector extension
  - Vector embeddings column (1536 dimensions for OpenAI ada-002)
  - HNSW index for fast similarity search
  - Indexes for efficient filtering by city and document type

  2. Go Module: travelknowledge/

  - models.go - Complete data models:
    - TravelDocument - Main document structure
    - DocumentType enum (historical, logistics, food, activities, nearby_places)
    - SearchQuery, SearchResult - Search interfaces
    - City, GeneratedContent - Content generation types
  - service.go - Query service with methods:
    - GetCityDocuments() - Get all docs for a city
    - SemanticSearch() - Vector similarity search
    - HybridSearch() - Combined text + vector search
    - GetCityInfo() - Aggregated city information
    - ListCities(), GetDocumentStats() - Utilities

  - Generates 5 content categories per city
  - Automatic chunking for large content
  - Metadata extraction and storage

  - Export functionality

  - One-command generation
